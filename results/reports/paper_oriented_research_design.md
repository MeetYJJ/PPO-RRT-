# 面向论文发表的研究设计与创新方向

## 一、建议的论文主线

建议将论文主题定义为：

> 面向目标未来位姿不确定性的搜索反馈驱动 SE(3)-RRT* 自适应采样规划。

核心问题不是“PPO 能否替代 RRT*”，而是：

> 在六自由度、狭窄通道和目标位姿预测不确定性同时存在时，能否利用搜索反馈动态分配全局探索、目标引导和局部优化资源，在不改变 RRT* 几何可行性机制的前提下提高规划成功率和首次可行路径效率？

## 二、可发表的创新点

建议只保留一个主创新，其他作为支撑模块。

### 主创新：不确定性感知的搜索资源调度

底层 RRT* 保持节点扩展、碰撞检查、父节点选择和重连；上层策略根据搜索状态和目标位姿预测协方差，输出采样资源分配：

\[
a_t=(p_g,p_{goal},p_l,p_u,\eta,\sigma_u).
\]

其中 `p_g` 为全局探索比例，`p_goal` 为目标引导比例，`p_l` 为局部路径比例，`p_u` 为不确定性采样比例，`η` 为扩展步长，`σ_u` 为不确定性采样尺度。

### 支撑创新 1：SE(3) 搜索状态观测

观测包含：目标位置/姿态误差、树规模、有效扩展率、停滞长度、最优路径改善率、剩余预算和六维预测协方差。重点是证明这些量对搜索决策具有可解释意义。

### 支撑创新 2：保持全局探索的安全策略

强制全局采样概率满足：

\[
p_g\ge p_{min}>0.
\]

这避免策略长期局部化，并为后续讨论可达性和采样覆盖性提供基础。

不建议把“使用 PPO”单独作为创新点。PPO 只是实现资源调度的一种学习器，创新重点应放在状态、动作与规划器融合机制上。

## 三、必须回答的研究假设

- H1：连续状态相关采样比固定混合采样提高成功率或降低首次可行时间。
- H2：优势在中等和困难场景、狭窄通道和大姿态差异场景更明显。
- H3：加入目标位姿不确定性后，高不确定性场景的终端误差和成功率更稳定。
- H4：改进方法可能增加单次决策计算开销或牺牲部分路径代价，因此需要报告完整代价。
- H5：PPO 学习策略应优于手工连续策略；若不能，则论文应将手工策略作为最终方法并如实说明 PPO 未带来增益。

## 四、实验分层

### 阶段 A：几何与基线验证

算法：标准 RRT*、固定目标偏置、固定混合、文献启发全局—局部采样。三种难度各 50 个场景，固定种子 0--49。

目的：确认所有算法使用相同约束，并建立成功率、首次可行扩展数、总时间、路径代价和净空基线。

### 阶段 B：手工连续策略

比较固定混合与连续状态相关策略。控制相同预算和随机种子，重点分析停滞长度、有效扩展率和模式频率与成功结果的关系。

### 阶段 C：不确定性消融

设置四个预测标准差等级，位置和姿态分别控制：

- 无不确定性输入；
- 手工不确定性采样；
- 相同不确定性下不同采样策略；
- 自适应安全裕度单独消融。

安全裕度不能与采样策略同时变化，否则无法归因。

### 阶段 D：PPO 学习

训练场景、验证场景、测试场景按独立种子划分，例如 100/30/50。测试集只在最终冻结超参数后运行。PPO 必须与手工策略共享动作空间、观测归一化和规划预算。

## 五、论文主实验矩阵

| 方法 | 搜索反馈 | 不确定性输入 | 学习 | 作用 |
|---|---:|---:|---:|---|
| RRT* | 否 | 否 | 否 | 传统基线 |
| 固定混合 | 否 | 否 | 否 | 多模式基线 |
| 文献启发基线 | 在线奖励 | 否 | 非 PPO | 文献对照 |
| 手工连续策略 | 是 | 否 | 否 | 机制验证 |
| PPO-RRT* | 是 | 否 | 是 | 学习贡献 |
| PPO-U-RRT* | 是 | 是 | 是 | 完整方法 |

## 六、评价指标与统计方法

主要指标：成功率、首次可行扩展次数、首次可行时间、总规划时间、扩展次数、碰撞检查次数、成功路径综合代价、平移长度、姿态变化量、最小净空和终端误差。

同一场景采用配对比较。成功率使用 paired bootstrap 或 McNemar 检验；连续指标使用配对 bootstrap、Wilcoxon signed-rank，并报告 Cliff's delta 或配对效应量。成功路径代价只在成功样本中统计，同时报告失败率；不能将失败路径记为零代价。

每个结论都应同时给出均值/中位数、95% 置信区间、样本数和效应量。多算法比较使用 Holm 校正。

## 七、可接受的论文结论

如果 PPO-U-RRT* 只在困难场景提高成功率，但路径代价增加，应表述为“在困难场景下提高可行性，代价是路径质量或计算量增加”。如果 PPO 没有超过手工策略，应将手工策略作为有效机制，论文结论改为“搜索反馈驱动采样有效，PPO 学习尚未证明优于规则策略”。

只有在独立测试集上同时满足以下条件，才建议声称方法有效：成功率置信区间明显改善；首次可行时间或扩展数下降；路径代价和净空没有不可接受恶化；结果在三种难度和不同不确定性等级下可复现。

## 八、当前进入下一阶段的条件

当前已有 150 个配对基线场景，已经支持“连续状态相关采样值得进一步研究”的初步结论，但还不足以支持 PPO 创新。进入 PPO 前必须完成：

1. 文献启发基线的 informed sampling 更忠实实现；
2. 不确定性数据接口和四级受控实验；
3. 训练/验证/测试场景隔离；
4. 运行时间、净空和失败原因完整记录；
5. PPO 与手工连续策略的严格配对比较。

论文贡献应围绕“搜索反馈与不确定性驱动的采样资源调度”组织，而不是围绕“使用 PPO”组织。
