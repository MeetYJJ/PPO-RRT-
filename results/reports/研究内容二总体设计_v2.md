# 研究内容二总体设计（v2）

## 1. 研究定位

本研究面向空间非合作目标的六自由度接近规划。研究内容一提供目标未来位姿预测、预抓取姿态参考和预测不确定性；研究内容二接收这些信息，在 SE(3) 位姿空间中规划满足避障约束和终端相对位姿约束的接近路径；研究内容三负责相对位姿稳定后的机械臂精细抓取控制。

研究内容二不研究视觉预测器、航天器动力学控制、机械臂控制、时间最优交会或移动目标时间同步。当前工程解决的是静态预测终端位姿约束下的六自由度路径—姿态协同规划。

## 2. 核心科学问题

固定采样分布无法同时适应不同的搜索阶段和目标预测可靠程度。本研究关注：

> 如何利用 RRT* 搜索反馈和目标未来位姿预测不确定性，动态分配全局探索、目标引导、局部优化和不确定性感知采样资源，并检验这种调度是否提高复杂场景中的规划可行性和搜索效率。

## 3. 递进算法主线

当前算法不是相互替代的几个孤立版本，而是三层递进关系。

### 第一层：标准 SE(3)-RRT*

RRT* 保留以下几何过程：

- 位置加四元数位姿节点；
- 综合位置—姿态距离；
- SLERP 插值和 Steering；
- 最近邻搜索；
- 碰撞检查；
- 最优父节点选择；
- 邻域重连；
- 终端位置和姿态容差检查。

航天器包络目前使用最大半尺寸保守球近似，障碍物使用球体，边通过离散位姿插值检查。当前目标是静态预测终端位姿，不包含移动目标时间同步。

### 第二层：连续状态相关手工策略

这是目前已有初步实验依据的机制基线。策略根据搜索反馈平滑调整全局、目标和局部采样比例：

- 未找到路径时保留目标引导和全局探索；
- 已找到路径后增加局部路径采样；
- 搜索停滞时提高全局探索比例；
- 全局探索概率始终保留非零下限。

在此前 150 个配对场景中，该策略总体成功率为 0.607，高于标准 RRT* 的 0.18 和固定混合采样的 0.40。其成功路径综合代价为 1.424，高于固定混合采样的 1.171。因此已有证据支持“搜索反馈调度采样资源具有潜力”，但不支持“所有路径质量指标都得到改善”。

连续策略不会被删除。它承担三个作用：

1. 验证搜索反馈调度本身是否有效；
2. 作为 PPO 的手工教师和行为基线；
3. 作为判断 PPO 是否真正学到额外能力的参照。

### 第三层：PPO 学习采样资源分配

PPO 学习搜索反馈、不确定性和采样动作之间的关系。第一版保留四个离散动作：

1. 全局随机采样；
2. 目标引导采样；
3. 局部路径采样；
4. 不确定性引导采样。

一个动作控制一个搜索窗口，当前窗口最多执行 10 次 RRT* 扩展。窗口结束后记录状态、实际动作、旧 log probability、旧 value、窗口奖励、下一状态、下一状态价值、持续扩展次数和终止标志。

后续只有在离散动作版本完成对照后，才考虑让 PPO 输出连续采样比例。如果连续 PPO 没有超过手工连续策略，则应如实报告手工机制有效而学习策略未带来额外收益。

## 4. 不确定性机制

目标预测位姿表示为：

\[
\hat T_g=(\hat p_g,\hat q_g).
\]

局部 SE(3) 位姿扰动为：

\[
\xi=[\delta p_x,\delta p_y,\delta p_z,\delta\phi_x,\delta\phi_y,\delta\phi_z]^T,
\]

协方差为：

\[
\Sigma_\xi\in\mathbb R^{6\times6}.
\]

位置单位为米，姿态扰动单位为弧度。协方差需要进行对称化、正定性检查和数值稳定化。候选终端位姿应依据局部扰动生成，并通过合法边界和碰撞检查。

不确定性不是只作为 PPO 观测输入。它必须真正改变候选位姿分布：

- 位置不确定性影响目标位置采样范围；
- 姿态不确定性影响目标姿态候选分布；
- 位置和姿态覆盖缺口用于判断应继续目标引导、增加姿态探索还是恢复全局探索。

当前已有六维协方差接口、位置扰动、位置—姿态耦合采样和联合采样候选实现，但尚未完成真实预测器数据接入和大样本正式验证。此前小规模结果表明，直接扩大位置—姿态扰动在简单和困难场景有潜在收益，在中等场景可能退化。因此下一步应研究搜索树可达性与不确定性的耦合，而不是机械增大扰动尺度。

## 5. PPO 状态、动作和奖励

最小可验证状态包括：

\[
s_t=[e_p,e_R,g_p,g_R,\rho_{valid},h_t,\Delta J_t,b_t,I_{feasible},u_p,u_R].
\]

其中：

- (e_p)：目标位置误差；
- (e_R)：目标姿态误差；
- (g_p,g_R)：搜索树的位置和姿态覆盖缺口；
- (ho_{valid})：有效扩展率；
- (h_t)：连续停滞长度；
- (Delta J_t)：最优路径代价实际改善；
- (b_t)：搜索进度或剩余预算；
- (I_{feasible})：是否已找到满足终端约束的路径；
- (u_p,u_R)：位置和姿态预测不确定性。

奖励采用窗口级定义：

\[
R_t=R_{first}+w_J\max(0,J_{t-1}-J_t)-w_cC_t-w_bB_t.
\]

首次找到满足终端约束的可行路径才产生较大正奖励；单纯接近目标不等同于成功。窗口持续时间为实际扩展次数 (k_t)，GAE 使用对应的 (gamma^{k_t}) 折扣。真实终止状态不 bootstrap，rollout 截断状态使用下一状态价值。

当前工程已经实现 Actor-Critic、GAE、PPO clipped objective、价值损失、熵正则、梯度裁剪、窗口 rollout 和模型保存加载。真实 RRT* smoke 已完成，但训练轮数很少，不能据此声称 PPO 性能有效。

## 6. 实验对照关系

正式研究应按以下关系展开：

| 方法 | 搜索反馈 | 不确定性 | 是否学习 | 作用 |
|---|---:|---:|---:|---|
| 标准 RRT* | 否 | 否 | 否 | 传统基线 |
| 固定混合 RRT* | 否 | 否 | 否 | 多模式基线 |
| 连续状态相关策略 | 是 | 否 | 手工规则 | 已有机制基线 |
| 手工不确定性策略 | 否或弱 | 是 | 手工规则 | 不确定性消融 |
| PPO-RRT* | 是 | 否 | 是 | 搜索反馈学习消融 |
| PPO-U-RRT* | 是 | 是 | 是 | 完整候选方法 |

所有算法使用相同场景、障碍物、起终点、碰撞判定、终端容差、路径代价和搜索预算。失败路径不计为零代价。

## 7. 已实现、初步观察和待验证事项

已实现：SE(3)-RRT* 基础流程；多种采样器；手工连续状态相关策略；六维协方差接口；真实 PPO 窗口 rollout；GAE 和 PPO 更新；模型保存加载。

初步观察：连续状态相关策略在已有配对实验中提高成功率，但路径代价存在增加；位置—姿态耦合不确定性采样的表现依赖场景；PPO smoke 仅证明训练链路可运行。

待验证：PPO 是否超过手工连续策略；不确定性是否带来独立收益；搜索反馈和不确定性是否存在额外耦合收益；门控 MLP 是否优于普通 MLP；模型在未见场景和未见不确定性等级下是否泛化。

## 8. 进入正式训练的条件

正式 PPO 训练前必须完成：

1. 手工连续策略与固定混合策略的独立测试确认；
2. 无不确定性、固定不确定性和搜索反馈联合不确定性消融；
3. 训练、验证和测试场景独立划分；
4. 窗口动作、奖励、log probability 和 GAE 的一致性测试；
5. PPO 与手工策略使用相同状态、动作窗口和搜索预算。

最终论文不应声称 PPO 一定优于 RRT*。可接受的结论包括：连续搜索反馈机制提高复杂场景可行性；不确定性在部分预测误差等级下改善终端鲁棒性；PPO 是否进一步超过手工机制由独立测试结果决定。
