# 搜索阶段自适应采样正式验证（初步版）

本实验使用三个难度、8 个配对随机场景、100 次扩展预算，比较标准 RRT*、固定混合采样和搜索阶段自适应采样。所有算法使用相同起终点、障碍物、碰撞检测、终端约束和随机种子。成功率置信区间由 2000 次 bootstrap 重采样获得。

| 难度 | 标准 RRT* | 固定混合 | 自适应 |
|---|---:|---:|---:|
| 简单 | 0.250 [0, 0.500] | **0.625 [0.250, 0.875]** | 0.250 [0, 0.500] |
| 中等 | 0.125 [0, 0.375] | 0.125 [0, 0.375] | 0.125 [0, 0.375] |
| 困难 | 0.000 [0, 0.000] | 0.125 [0, 0.375] | 0.000 [0, 0.000] |
| 合计 | 0.125 [0, 0.250] | **0.292 [0.125, 0.500]** | 0.125 [0, 0.250] |

当前结果不支持自适应规则优于固定混合采样。原因可能是预算较小，策略在前 45 次扩展中固定进行全局探索，尚未形成有效树就消耗了近一半预算；同时“找到路径后局部采样”的阶段在多数失败场景中没有触发。

因此下一步应让 PPO 学习阶段切换阈值和连续采样比例，而不是使用固定阈值。该结果仍然有价值：它排除了一个过于简单的手工阶段规则，说明创新点不能只写成固定 if/else 调度。
